# Windows Maintenance Toolbox

## 简介

一个 Windows 批处理（.bat）系统维护工具箱，以菜单形式集成常用的系统清理、诊断、维护操作，并附带语音播报反馈。

运行时会自动请求管理员权限。

## 功能列表

| 按键 | 功能 |
|---|---|
| A | 查看系统信息 |
| B | 清理临时文件和回收站 |
| C | 网络诊断（DNS刷新、连接状态、ping测试） |
| D | 查看进程列表 |
| E | 磁盘空间查看 / chkdsk 磁盘检查 |
| F | 开启系统防火墙 |
| G | 快捷打开任务管理器 / 控制面板 / 注册表 / 程序卸载 |
| H | 切换高性能电源模式 |
| I | 按日期建目录 + 列出隐藏文件 |
| J | 编辑 hosts 文件 |
| L | 查看局域网设备（ARP表） |
| M | 实时监控 CPU / 内存占用 |
| T | CPU 压力测试 |
| P | 文本 Base64 编码 |
| U | 查看已安装软件列表 |
| W | 备份当前驱动 |
| R | 系统文件修复（sfc / dism） |
| O | 定时关机 / 取消定时关机 |
| N | 向 hosts 添加屏蔽域名 |
| Z | 按进程名查找进程 |
| MD5 | 计算文件 MD5 校验值 |
| K | 添加桌面右键快捷菜单 |
| S | 开关语音播报 |
| X | 随机切换终端配色 |
| V | 自定义语音播报内容 |
| RESET | 重置 Winsock / IP 网络栈 |
| FIX | 修复系统启动记录（bootrec / bcdboot） |
| BIOS | 读取硬件序列号 / UUID |
| Q | 退出 |

## ⚠️ 使用须知

- 本脚本会自动请求管理员权限，请仅在你信任并了解其行为的电脑上运行。
- **B（清理）** 会永久删除临时文件和回收站内容，不可恢复。
- **RESET（网络栈重置）** 和 **FIX（启动修复）** 影响面较大，误操作可能导致网络配置异常或系统启动问题，非必要不要执行，执行前建议确认当前系统状态正常。
- **O（定时关机）** 会实际安排系统关机，注意保存工作。

## 使用方法

双击运行 `windows_maintenance_toolbox.bat`（或右键"以管理员身份运行"），在菜单中输入对应字母/关键词执行功能。

## 依赖

- Windows 系统（cmd / 批处理）
- 语音播报依赖系统自带的 SAPI（Windows 内置，无需额外安装）
